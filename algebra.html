1.Teorema Fundamental del Álgebra Lineal

Sea A una matriz real de tamaño m × n con rango rango(A) = r. El Teorema Fundamental del Álgebra Lineal establece las relaciones ortogonales y dimensionales entre los cuatro subespacios fundamentales asociados a A.

Espacio de columnas C(A):subespacio de $\mathbb{R}^m$, con $\dim(C(A)) = r$.
Espacio nulo N(A):subespacio de $\mathbb{R}^n$, con $\dim(N(A)) = n - r$.
Espacio de filas C(Aᵀ):subespacio de $\mathbb{R}^n$, con $\dim(C(A^T)) = r$.
Espacio nulo izquierdo N(Aᵀ):subespacio de $\mathbb{R}^m$, con $\dim(N(A^T)) = m - r$.

La ortogonalidad fundamental se expresa como:

$$C(A^T) \perp N(A) \ \text{ en } \mathbb{R}^n, \qquad C(A) \perp N(A^T) \ \text{ en } \mathbb{R}^m$$

Dimensiones y consistencia de un sistema

Las dimensiones de cada par de subespacios complementarios suman la dimensión del espacio ambiente:

$$\dim C(A)+\dim N(A)=n,\qquad \dim C(A^T)+\dim N(A^T)=m.$$

El sistema $Ax=b$ tiene solución exactamente cuando $b\in C(A)$. Si $x_0$ es una solución, todas las soluciones son $x=x_0+z$, donde $z\in N(A)$. Por eso el espacio nulo describe todas las direcciones en las que una solución puede cambiar sin alterar el resultado.

Procedimiento para analizar una matriz de 2 × 3

  1. Reduce la matriz por filas hasta obtener una forma escalonada. Las operaciones elementales por filas conservan las soluciones del sistema homogéneo.
  2. Cuenta las columnas con pivote: ese número es el rango $r$. Las columnas pivote de la matriz original forman una base para $C(A)$; las filas no nulas de la forma escalonada forman una base para el espacio de filas.
  3. Resuelve $Ax=0$ usando la forma escalonada. Identifica las variables libres y escribe la solución como combinación lineal de vectores; estos vectores forman una base de $N(A)$.
  4. Usa $N(A^T)=C(A)^\perp$: también puedes resolver $A^Ty=0$ para hallar una base del espacio nulo izquierdo.
  5. Comprueba las dimensiones: $\dim C(A)=\dim C(A^T)=r$, $\dim N(A)=3-r$ y $\dim N(A^T)=2-r$.

Al ser una matriz de 2 × 3, tiene dos filas y tres columnas: su rango no puede exceder 2. Por tanto, el espacio nulo contiene al menos una dirección libre. Para un sistema $Ax=b$, verifica además si $b$ pertenece al espacio columna; si existe una solución particular, las demás se obtienen sumándole cualquier vector de $N(A)$.

2.Campos Finitos (Zp) y Características

Un campo (o cuerpo) es una estructura algebraica donde se pueden realizar operaciones de suma, resta, multiplicación y división (salvo por cero). Cuando el número de elementos es finito, se denomina campo finito o de Galois ($\mathbb{F}_q$).

2.1 Campos primos ℤp

Para cualquier número primo $p$, el conjunto $\mathbb{Z}_p = \{0, 1, \dots, p-1\}$ con la suma y multiplicación módulo $p$ forma un campo finito. Cada elemento distinto de cero tiene un inverso multiplicativo; por ejemplo, en $\mathbb{Z}_5$, $2^{-1}=3$ porque $2\cdot3=6\equiv1\pmod 5$. La primalidad importa: en $\mathbb{Z}_4$, el elemento 2 no tiene inverso, pues $2\cdot0=0$, $2\cdot1=2$, $2\cdot2=0$ y $2\cdot3=2$ módulo 4. Por tanto, $\mathbb{Z}_4$ no es un campo.

2.2 Característica y construcción de 𝔽₄

Los campos de característica 2 satisfacen $x + x = 0$ para todo elemento. El campo más pequeño es $\mathbb{F}_2 = \{0, 1\}$. Para construir extensiones como $\mathbb{F}_4$, se utiliza un polinomio irreducible de grado 2 sobre $\mathbb{F}_2$, por ejemplo, $f(x) = x^2 + x + 1$.

Sea $\alpha$ una raíz de $f(x)$, de modo que $\alpha^2 + \alpha + 1 = 0 \implies \alpha^2 = \alpha + 1$. Los elementos de $\mathbb{F}_4$ son $\{0, 1, \alpha, \alpha+1\}$.

En general, los campos finitos tienen $p^k$ elementos, donde $p$ es primo y $k$ es un entero positivo. Una extensión $\mathbb{F}_{p^k}$ puede construirse usando polinomios de grado menor que $k$ y reduciendo sus productos módulo un polinomio irreducible de grado $k$.

3.Descomposición en Valores Singulares (SVD)

La Descomposición en Valores Singulares (SVD) factoriza cualquier matriz real A de tamaño m × n en el producto de tres matrices:

$$A = U \Sigma V^T$$
U:matriz ortogonal $m \times m$ cuyas columnas son los vectores singulares izquierdos (autovectores de $AA^T$).
Σ:matriz $m \times n$ con elementos diagonales $\sigma_1 \ge \sigma_2 \ge \cdots \ge \sigma_p > 0$, llamados valores singulares (raíces cuadradas de los autovalores no nulos de $A^TA$ o $AA^T$).
V:matriz ortogonal $n \times n$ cuyas columnas son los vectores singulares derechos (autovectores de $A^TA$).

Proceso de cálculo

  1. Calcular $A^TA$ y obtener sus autovalores $\lambda_i$ y autovectores ortonormales $v_i$. Los valores singulares son $\sigma_i = \sqrt{\lambda_i}$.
  2. Construir la matriz $V = [v_1, v_2, \dots, v_n]$.
  3. Para cada $\sigma_i>0$, obtener $u_i = \dfrac{1}{\sigma_i} A v_i$. Si se necesita la SVD completa, completar estos vectores hasta formar una base ortonormal de $\mathbb{R}^m$.

Interpretación y aproximación de bajo rango

La matriz $V^T$ cambia las coordenadas de entrada, $\Sigma$ escala cada dirección y $U$ orienta el resultado en el espacio de salida. Las direcciones con valores singulares grandes son las que más amplifica la transformación. Los valores singulares cero corresponden a direcciones del espacio nulo.

Si se conservan solo los primeros $k$ valores singulares, se obtiene la mejor aproximación de rango $k$ de $A$ en norma de Frobenius:

$$A_k=\sum_{i=1}^{k}\sigma_i u_i v_i^T,\qquad \lVert A-A_k\rVert_F^2=\sum_{i=k+1}^{r}\sigma_i^2.$$

Esta propiedad explica usos como compresión de imágenes, reducción de ruido y análisis de datos. Por ejemplo, para $A=\begin{bmatrix}3&0\\0&1\end{bmatrix}$, los valores singulares son 3 y 1; conservar solo el primero da $A_1=\begin{bmatrix}3&0\\0&0\end{bmatrix}$ y el error de Frobenius es 1.

4.Análisis de Componentes Principales (PCA)

El análisis de componentes principales (PCA, por sus siglas en inglés) transforma un conjunto de variables posiblemente correlacionadas en nuevas coordenadas ortogonales. La primera componente apunta en la dirección de máxima varianza; cada componente siguiente captura la mayor varianza restante, bajo la condición de ser ortogonal a las anteriores.

Procedimiento matricial

  1. Organizar los datos en una matriz $X\in\mathbb{R}^{n\times p}$: filas para observaciones y columnas para variables.
  2. Restar la media de cada columna para formar la matriz centrada $X_c$.
  3. Si las variables tienen escalas o unidades distintas, estandarizarlas para que una escala numérica grande no domine el análisis.
  4. Calcular la covarianza $S=\dfrac{1}{n-1}X_c^T X_c$ y sus pares propios $Sv_j=\lambda_jv_j$, ordenados de mayor a menor.
  5. Proyectar los datos en los primeros $k$ ejes: $Z=X_cW_k$, donde $W_k=[v_1\ \cdots\ v_k]$.
$$\text{Proporción explicada por }v_j= \frac{\lambda_j}{\sum_{i=1}^{p}\lambda_i}.$$

Los eigenvectores de $S$ son las direcciones principales porque la varianza de los datos proyectados en un vector unitario $v$ es $v^TSv$. Maximizar esta expresión sujeto a $\lVert v\rVert=1$ conduce a la ecuación $Sv=\lambda v$. PCA también puede calcularse mediante la SVD de $X_c$: las columnas de $V$ son las direcciones principales y $\lambda_i=\sigma_i^2/(n-1)$.

Explora la dirección de proyección

En este ejemplo, $S=\begin{bmatrix}2.5&2.25\\2.25&2.5\end{bmatrix}$ tiene eigenvalores 4.75 y 0.25. Por tanto, la primera componente explica el 95% de la varianza total.

PCA es una técnica descriptiva y lineal: puede facilitar visualización y compresión, pero no demuestra causalidad. Conviene revisar la escala de las variables y recordar que valores atípicos pueden cambiar las componentes.

5.Códigos lineales

Un código lineal binario de longitud $n$ y dimensión $k$ es un subespacio de $\mathbb{F}_2^n$ de dimensión $k$. Cada palabra del código es una cadena de bits y la suma se realiza componente a componente módulo 2 (XOR). Una matriz generadora $G$ permite formar palabras de código como $c=wG$, con un mensaje $w\in\mathbb{F}_2^k$.

Un código también puede describirse mediante una matriz de comprobación de paridad $H$: una palabra $c$ pertenece al código si $Hc^T=0$. Para un código $[3,2]$ con una sola ecuación de paridad, $H=(h_1\ h_2\ h_3)$ es un vector binario no nulo y el código consta de las cuatro soluciones de $h_1c_1+h_2c_2+h_3c_3=0$ en $\mathbb{F}_2$.

Hay exactamente siete de estos códigos: cada uno corresponde a uno de los siete vectores no nulos de $\mathbb{F}_2^3$. En todos, $k=2$ y hay $2^2=4$ palabras. Selecciona una ecuación para ver sus palabras, una matriz generadora y su distancia mínima.

La distancia de Hamming cuenta las posiciones distintas entre dos palabras. Un código de distancia mínima $d$ detecta hasta $d-1$ errores y corrige hasta $\left\lfloor\dfrac{d-1}{2}\right\rfloor$. Por ejemplo, el código de paridad par $c_1+c_2+c_3=0$ tiene distancia 2: detecta un error, pero no puede corregirlo de forma unívoca.
